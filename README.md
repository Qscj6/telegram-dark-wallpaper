# Telegram Dark Dynamic Wallpaper

基于 Telegram 官方聊天背景矢量图案与 `twallpaper` 流体渐变引擎打造的**纯离线暗黑动态桌面壁纸**。每次打开都会随机切换不同的官方涂鸦图案与暗色系动态配色组合。

## 特性

- **收录全部 19 套 Telegram 官方涂鸦图案**：
  `Animals`、`Astronaut Cats`、`Beach`、`Cats and Dogs`、`Christmas`、`Fantasy`、`Late Night Delight`、`Magic`、`Math`、`Paris`、`Games`、`Snowflakes`、`Space`、`Star Wars`、`Sweets`、`Tattoos`、`Underwater World`、`Unicorns`、`Zoo`
- **暗色系动态流光配色**：纯黑（`#000000`）底色镂空发光，内置 16 套暗黑系精选渐变配色（极夜极光、暗夜紫晶、赛博霓虹、东京夜色、黑曜石余烬等）及无限和谐暗色随机生成算法。
- **每次打开自动随机切换**：自动记录上一次使用的图案，避免连续重复。
- **纯离线单文件**：所有矢量 SVG 与渲染引擎均已内嵌至 `index.html`，无需联网即可在桌面或浏览器运行。
- **随时手动切换**：在桌面空白处**双击鼠标**，或点击桌面后按键盘 **`R`** / **`Space（空格）`** 即可即时随机切换下一套图案与配色。

## 使用方法

### 1. Lively Wallpaper（推荐，Windows 免费开源）
1. 克隆或下载本仓库中的 `index.html`。
2. 打开 **Lively Wallpaper**，点击右上角 **`+` 添加壁纸**，将 `index.html` 直接拖入即可。
3. 也可以在 GitHub 仓库设置中开启 **GitHub Pages**，之后直接在 Lively 中填入 Pages 网址作为网页壁纸。

### 2. 浏览器直接预览
用 Chrome / Edge 等现代浏览器直接打开 `index.html` 即可全屏预览（支持鼠标滚轮互动加速）。
